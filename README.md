Class Wall

IT 110 Activity: Cookies, Sessions and PostgreSQL

Project Description

Class Wall is a simple message board created using PHP and PostgreSQL. Visitors can post messages, search for messages, and see messages posted by other users. 
Also it uses cookies to remember a visitor's name and sessions to count their visits.

Features
- Post messages using a name and message.
- Save messages in PostgreSQL.
- Display messages from newest to oldest.
- Search for messages.
- Remember the visitor's name using cookies.
- Count visits using sessions.
- Use prepared statements for database security.
- Escape displayed data using htmlspecialchars().

Technologies Used
- PHP
- PostgreSQL
- HTML
- pgAdmin 4
- XAMPP

Files
- index.php – Main page of the message board.
- db.php – Database connection using PDO.
- schema.sql – Creates the messages table.
